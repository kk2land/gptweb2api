## 固定依赖

- Go：1.27.3；上游 Tunnel SDK 要求 Go 1.27，不能按旧项目的 Go 1.23 假设构建。
- `github.com/openai/tunnel-client`：`v0.0.19-0.20261027192628-bf9e87efa7f5`，对应 `bf9e87efa7f5efadb44744e15e1f2857b246bf97`。
- `github.com/modelcontextprotocol/go-sdk`：`v1.7.0`。
- `github.com/BurntSushi/toml`：`v1.5.0`。
- `modernc.org/sqlite`：`v1.34.5`，纯 Go。
- Ego Native API：按官方 wiki 的 2026-08-29 修订实现；部署版本尚未实测。

所有间接依赖和校验和记录在 go.mod/go.sum。未复制参考项目的业务实现；没有引入自建 relay、独立 tunnel-client 或额外 stdio MCP 子进程。

## 离线测试依据

Go 测试实际启动所固定的官方 SDK，对本地模拟控制面验证 `start_task` 和 `complete_task`；另验证 MCP 2.0 `server/discover` 的 events 能力及 `events/list` 能穿过 SDK。内存 MCP 测试覆盖文件读写、相同补丁重试、不同补丁冲突、目录穿越、目录外符号链接与目录替换。

任务测试覆盖晚订阅结果的等待者、SQLite 终态、同会话串行、不同会话独占槽、清理前不释放槽、队列满、排队期限、HTTP 断开继续执行、取消/完成竞争、重启未知状态与流中错误。事件测试通过模拟签名 callback 完成校准、完整消息领取、Dot 互斥、租约过期和 outbox 原字节重试。

Ego 调度测试覆盖提交不确定时只发送一次、页面清理和脚本指纹持久化。JS 测试验证语法、精确模型匹配、项目/会话/插件/历史不匹配时拒绝操作。页面 DOM 选择器没有在真实登录账号验证，不能以这些测试代替浏览器验收。

真实验收按主计划依次进行。Dot 默认保持关闭；模型未就绪时拒绝新任务，不跨后端替换或重放。

## Space 名称配置变更

新增可选 `[ego].space_name`，指定名称时复用或创建同名 Space，空值保留旧的槽命名。后续并发槽追加数字后缀；不能让两个槽绑定同一 Space。配置更改后不沿用旧的页面路由，保留账号和插件身份。

普通用户 Space 的首次按名选用通过原生 `claimTaskSpace(id)` 实现，不改名；其契约核对自上游 `docs/native-bindings-api.md`。已经绑定的 Space 被用户接管时停止操作，不自动取得控制。新增离线测试覆盖名称/默认值、重名与 Profile 冲突、配置变化后的路由清除、槽 ID 独占和用户接管。真实浏览器验收边界保持不变。
